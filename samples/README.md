# Lumen

Juego de **exploración** con *combate por turnos* hecho en Unity 6. ~~Antes era 2D.~~

## Instalación

1. Clona el repo.
2. Abre la carpeta con Unity Hub.
   - Versión: `6000.0.23f1`

> **Nota:** el proyecto usa URP.

```csharp
var player = GetComponent<PlayerController>();
```
